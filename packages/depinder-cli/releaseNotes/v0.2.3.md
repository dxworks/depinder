# Black Duck category reports

- Added `addCategoriesToBlackDuckReports` to create category-enriched dependency reports from existing Black Duck transform outputs.
- `transformBlackDuckReports` can now also write `_dependencies_by_category.csv` and `_dependencies_sources_by_category.csv` with `--repoCategories`.
- Project path extraction now supports `v`-prefixed versions and wildcard version segments such as `9.0.*`.
- Add poetry to known path segments.
