# Black Duck category reports

- Added `addCategoriesToBlackDuckReports` to create category-enriched dependency reports from existing Black Duck transform outputs.
- `transformBlackDuckReports` can now also write `_dependencies_by_category.csv` and `_dependencies_sources_by_category.csv` with `--repoCategories`.
- Black Duck dependency reports now include `Version id`, which category reports use to join dependency rows to source rows.
- Project path extraction now supports `v`-prefixed versions and wildcard version segments such as `9.0.*`.

# Framework version extraction

- CSV output now quotes field values containing commas, keeping framework versions in one column.
- Repeated framework XML nodes are represented with ` | ` between node values.
- Added regression coverage for comma-containing CSV values and repeated conditional framework nodes.
- When a project has no framework version, extraction now searches `.props` files in its directory and parent directories, stopping before scan root.
- Project-declared framework versions still take precedence over inherited `.props` values.
- Props-hierarchy traversal is shared by framework fallback and `$(Property)` resolution.
