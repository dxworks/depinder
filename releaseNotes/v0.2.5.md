# Framework version extraction

- Fixed `extractFrameworkVersion` hanging when `<projectPath>` ends with a path separator and a .NET project inherits its framework from `.props` files.
- Parent `.props` lookup now normalizes the scan root before comparison and stops safely at the filesystem root.
- Extraction now checks `.props` files at the scan root, including `Directory.Build.props`, while preserving nearest-parent precedence.
- Added regression coverage for trailing-separator project paths.
